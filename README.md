#### [Genjam & Spin](https://github.com/tanvinwaseef/genjam-and-spin)
*Context-aware social party app with procedural physics and AI prompt tailoring.*

- **Highlights:** Solves real-world truth-or-dare deadlocks with an interactive, personality-driven bottle selector and situation-specific game modes (`Family`, `Friends`, `Cousins`, `Couples`).
- **Engineering focus:** Dynamic prompt-engineering pipelines allowing users to bring their own API keys for real-time contextual question/dare generation without awkward group friction.

*A zero-noise, end-to-end encrypted private space designed exclusively for two.*
